# 数据分析可视化网站（Streamlit + Pandas + Plotly）

> 可视化导论课程作业 —— 一个零代码交互式数据分析与可视化平台。
> 打开网页即自动加载经典的鸢尾花（Iris）数据集，也可以上传任意 CSV 文件进行分析。

---

## 一、项目简介

本项目基于 **Streamlit** 快速搭建 Web 界面，以 **Pandas** 作为数据分析引擎，
用 **Plotly** 绘制可交互图表，实现了从“数据加载 → 数据理解 → 筛选查询 →
统计分析 → 可视化展示”的完整数据分析闭环，并支持 **中文 / 英文一键切换**。

## 二、功能亮点

| 模块 | 功能 | 对应 Pandas / Plotly 能力 |
| --- | --- | --- |
| 数据加载 | 打开网页自动加载 150 条鸢尾花默认数据；支持上传自己的 CSV（自动兼容 UTF-8 / GBK 编码） | `pd.read_csv` |
| 数据集概览 | 指标卡展示行数、列数、数值列/类别列数量、缺失数、重复行数；字段类型表；前 5 行速览 | `df.shape`、`df.dtypes`、`df.head`、`df.isna`、`df.duplicated` |
| 数据表格预览 | 自由勾选展示列、滑块控制显示行数、一键下载当前视图 | 列选择、`df.head(n)`、`df.to_csv` |
| 多列筛选 | 可同时对多列叠加条件：数值列用双向滑块做区间筛选，类别列用多选框筛选；结果可导出 | 布尔索引、`between`、`isin`、多条件逻辑与 |
| 统计描述 | 数值列输出 count/mean/std/min/四分位数/max；类别列输出 unique/top/freq | `df.describe()` |
| 缺失值检测 | 总体缺失指标 + 逐列缺失数量/比例明细表 + 缺失分布柱状图 | `df.isna().sum()` |
| 交互式可视化 | 图表页提供**三种分析方式**：① **数据故事线**（五章引导式分析，默认模式，详见第三章）；② 分析问题向导（选一个分析问题自动配好图表与结论）；③ 自由作图（10 种图表 X/Y/Z 轴自由搭配，含 3D 散点图、小提琴图、密度热力图等）。三种模式的图表均带统计标注与自动解读 | `plotly.express`、`groupby().mean()`、`np.corrcoef`、`np.polyfit` |
| 顶部导航与主题 | 5 个页面通过**顶部导航栏**切换（`st.navigation(position="top")`，带 Material 图标），当前页蓝金胶囊高亮；侧边栏一键切换**白天 / 夜间模式**。夜间为深空蓝黑科技风：蓝金光晕背景、全部文字颜色显式覆盖、下拉/滑块/折叠面板深色化；**所有 Plotly 图表经统一 `show_plotly()` 出口以 `theme=None` 渲染**（避开 Streamlit 浅色主题强制覆盖），绘图区/网格/刻度随主题换肤；数据表格用 `invert+hue-rotate` 滤镜深色化且色相不变 | `st.navigation`、`st.Page`、`st.plotly_chart(theme=None)`、主题 CSS |
| 视觉设计 | **深空蓝 + 科技金科技风**（全站只用蓝/青/金/黑，无红橙系）：蓝金渐变标题、渐变指标卡（左侧金条+阴影）；图表统一使用自定义蓝金青分类调色板与"深蓝→蓝→青→金"连续色带，相关热力图用蓝-金发散色，昼夜两套主题下均统一 | 自定义 CSS + Plotly 自定义调色板 |
| 双语切换 | 侧边栏 中文 / English 一键切换，全部标签、提示、图表标题一一对应 | i18n 字典方案 |
| 交互细节 | 图表支持悬停查看数值、3D 图鼠标拖动旋转、框选缩放、图例点击过滤、导出 PNG；筛选结果/预览可下载 CSV | Plotly 工具栏 + Streamlit download_button |

### 默认数据集说明

`default_data.csv` 为经典 **Iris 鸢尾花数据集**（150 行 × 5 列），字段含义：

| 字段 | 含义 |
| --- | --- |
| sepal_length | 花萼长度（cm） |
| sepal_width | 花萼宽度（cm） |
| petal_length | 花瓣长度（cm） |
| petal_width | 花瓣宽度（cm） |
| species | 类别：setosa（山鸢尾）/ versicolor（变色鸢尾）/ virginica（维吉尼亚鸢尾），各 50 条 |

## 三、数据故事线模块详解（重点）

### 3.1 为什么需要“数据故事线”

自由作图回答的是“**能不能画**”——用户自己选 X/Y 轴，图能出来；
但对不熟悉数据分析的观众（老师、同学）来说，打开页面后往往不知道
“**先看什么、后看什么、这张图说明了什么**”。

数据故事线把一套经典的数据分析套路固化为**五章式引导**：
每一章只回答一个具体问题，配一张（组）图和一句由 Pandas 实时计算的
自动结论，像翻演示文稿一样一步步走完“从数据到结论”的完整过程，
可直接作为分析报告或答辩讲解的叙事主线。

### 3.2 入口：图表页的三种分析方式

点击顶部导航栏中的「可视化图表」，页面顶部的单选项可切换三种模式：

| 模式 | 定位 | 适用场景 |
| --- | --- | --- |
| **数据故事线**（默认） | 按固定章节顺序引导分析，图 + 结论逐章呈现 | 第一次分析数据、课堂演示、撰写报告 |
| 分析问题向导 | 从 5 个分析问题中选一个，自动配好图表类型与字段 | 已有明确问题，想快速出图 |
| 自由作图 | 10 种图表、X/Y/Z 轴、分箱数全部自选 | 验证自己的其他猜想、高级探索 |

### 3.3 五个章节逐一说明

> 下例数字均来自默认鸢尾花数据集，实际数字会随上传的 CSV 自动重新计算。

#### 第 ① 章：单变量分布

- **回答的问题**：某个数值字段集中在哪个范围？均值与中位数是否重合？分布是否偏态？
- **图表**：直方图（带 rug 边际须线标出每个样本位置）；
  **金色虚线 = 均值**，**蓝色实线 = 中位数**，两条线的相对位置直接指示偏态方向。
- **交互**：左上角下拉框可切换任意数值字段。
- **自动结论示例**：*“sepal_length 的均值为 5.84、中位数为 5.80，分布大致对称。”*
  当均值明显大于中位数时会自动改为“右偏（存在偏大的极端值）”，反之亦然。

#### 第 ② 章：类别构成

- **回答的问题**：样本由哪些类别组成、各占多少、类别是否均衡？
- **图表**：占比环形图（`value_counts` 后绘制）。
- **交互**：可切换任意类别字段。
- **自动结论示例**：*“setosa 的记录数最多，共 50 条，占全部记录的 33.3%。”*
  （鸢尾花三类各 50 条，完全均衡。）

#### 第 ③ 章：类别差异

- **回答的问题**：不同类别在关键数值指标上差距有多大？各组内部是否分散、有无离群点？
- **图表（左右并排）**：
  - 左：分组均值**柱状图**（`groupby().mean()`，按数值降序），比较组间差异；
  - 右：分组**箱线图**，中线=中位数、箱体=25%~75% 分位数、圆点=离群值，比较组内分布。
- **智能字段推荐**：数值字段默认不是随便取第一个，而是自动选择
  **“组间均值最大值 ÷ 最小值”倍数最大**的字段——即类别区分度最高的指标
  （鸢尾花数据会自动推荐 petal_width）。也可手动下拉改选。
- **自动结论示例**：
  - *“按 species 分组后，virginica 的 petal_width 平均值最高（2.03），
    setosa 最低（0.25），最高约为最低的 8.24 倍，类别间差异显著。”*
  - *“versicolor 组 sepal_length 的四分位距最大（IQR = 0.70），分布最分散；
    按 1.5 倍 IQR 准则共检出 1 个离群点。”*

#### 第 ④ 章：变量关系

- **回答的问题**：两个数值字段是否一起变化？线性关系有多强？
- **图表**：散点图（默认按类别着色，可看出聚簇），叠加
  **金色虚线最小二乘趋势线**，悬停图例可见拟合方程 `y = ax + b`。
- **智能字段推荐**：自动选中全表**皮尔逊相关系数绝对值最大**的一对字段
  （鸢尾花数据自动选中 petal_length × petal_width）。
- **自动结论示例**：*“petal_length 与 petal_width 的皮尔逊相关系数 r = 0.96，
  呈强正相关。图中金色虚线为最小二乘线性拟合趋势线。”*
  相关程度按 |r| 自动分档：≥0.7 强相关、0.4~0.7 中等、0.2~0.4 弱、<0.2 几乎无线性关系，
  并区分正/负相关。
- 若手动把 X、Y 选成同一字段会给出提示，不绘制无意义图表。

#### 第 ⑤ 章：故事小结

- **回答的问题**：走完一遍后，最重要的几条结论是什么？
- **内容**：由 Pandas 自动汇总的编号“关键发现”卡片，通常包含：
  1. 相关性最强的字段对及其 r 值；
  2. 类别间差异最大的指标及最高/最低组倍数；
  3. 相对离散程度（变异系数 CV = std ÷ |mean|）最高的字段；
  4. 数据质量一条：缺失单元格数量与缺失率、重复行数
     （鸢尾花数据会如实报告“存在 1 行重复”）。
- 结尾提示可切换到「自由作图」继续验证其他猜想，形成“引导 → 自主探索”的闭环。

### 3.4 章节导航与状态记忆

- **顶部章节导航条**：五章按钮一字排开，当前章高亮（primary 样式），
  点击任意章节名可直接跳转，不必逐章翻；
- **进度条**：实时显示整体进度，下方文字标注“第 x / 5 章”；
- **底部按钮**：「上一章」「下一章」逐章推进，最后一章右侧按钮自动变为
  「重新走一遍」，点击回到第 ① 章；
- **状态记忆**：当前章节序号保存在 `st.session_state["story_step"]` 中，
  切换到其他页面再回来、或页面 rerun 后都会停留在原处，不会丢失讲解进度。

### 3.5 章节随数据集“动态裁剪”

五章并非写死，而是根据当前数据集的字段类型自动生成，**上传任何 CSV 都不会出现空白章节**：

| 条件 | 生成的章节 |
| --- | --- |
| 至少 1 个数值列 | 加入 ① 单变量分布 |
| 至少 1 个类别列 | 加入 ② 类别构成 |
| 同时有数值列与类别列 | 加入 ③ 类别差异 |
| 至少 2 个数值列 | 加入 ④ 变量关系 |
| 任何数据集 | ⑤ 故事小结始终存在 |

例如上传一个纯文本表时，故事线会自动只剩“② 类别构成 → ⑤ 小结”两章，
导航按钮、进度条、页码总数随之自适应。

### 3.6 自动结论的计算来源（答辩可讲）

故事线中没有任何写死的结论，全部由数据实时计算，中英双语同源：

| 结论内容 | Pandas / NumPy 实现 |
| --- | --- |
| 均值 / 中位数 / 偏态判断 | `Series.mean()`、`Series.median()`，比较两者相对大小 |
| 类别占比与最大组 | `Series.value_counts()` |
| 组间均值高低与倍数 | `groupby(col)[y].mean()`，最大值 ÷ 最小值 |
| 四分位距与离群点 | `groupby().quantile(0.25/0.75)`，按 1.5×IQR 准则布尔计数 |
| 相关系数与强弱分档 | `np.corrcoef`（等价 `df.corr()`），按阈值映射文案 |
| 散点趋势线与回归方程 | `np.polyfit(x, y, 1)` 一次最小二乘，`go.Scatter` 叠加（无需 statsmodels） |
| 直方图参考线 | Plotly `fig.add_vline()` |
| 关键发现汇总 | `corr()` / `groupby` / `std()` / `isna()` / `duplicated()` 组合 |

## 五、本地运行

### 1. 准备环境

需要 Python 3.9 及以上版本（官网下载安装：<https://www.python.org/downloads/>，
安装 Windows 版时勾选 **Add Python to PATH**）。

### 2. 安装依赖

在项目文件夹中打开终端（Windows 在地址栏输入 `cmd` 回车，或 PowerShell）：

```bash
# （推荐）创建并激活虚拟环境
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # macOS / Linux

# 安装依赖
pip install -r requirements.txt
# 若下载慢，可使用清华镜像源：
# pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 3. 启动网站

```bash
streamlit run app.py
```

浏览器会自动打开 <http://localhost:8501> ，即可看到自动加载的鸢尾花数据集。
停止服务：在终端按 `Ctrl + C`。

7. **15 秒**：上传一个自己的 CSV 文件，说明故事线章节会随字段类型自动裁剪、平台具有通用性，收尾。

## 八、核心实现要点（答辩可讲）

- 所有页面文案集中在 `TEXTS` 字典中，中文/英文使用相同的 key，切换语言即切换整套文案；
- 用 `@st.cache_data` 缓存数据读取结果，避免重复 IO；
- 多列筛选通过循环动态生成控件，并用布尔索引逐列收缩 DataFrame；
- 柱状图/折线图/面积图先用 `groupby().mean()` 聚合，解决“一类别多记录”的问题；
- 10 种图表的构建逻辑统一收敛到 `build_figure()` 函数中，按图表类型分发，
  主页面只负责参数校验与渲染，避免深层 if-else 嵌套；
- **数据故事线**的章节列表按字段类型动态拼装（数值列/类别列数量决定章节有无），
  当前章序号存入 `st.session_state["story_step"]`，支持顶部跳转与上一章/下一章导航；
- 故事线两处“智能推荐”均为纯 Pandas/NumPy 计算：`recommend_contrast_column()`
  选组间均值倍数最大的字段、`recommend_corr_pair()` 选 |r| 最大的字段对，
  让默认画面就是信息量最高的分析角度；
- 散点趋势线用 `np.polyfit(x, y, 1)` 做一次最小二乘并以 `go.Scatter` 叠加，
  不额外引入 statsmodels；离群点按箱线图 1.5×IQR 准则用布尔索引计数；
- 每张图下方的自动结论由 `build_insight()` 统一生成，数字全部实时计算，
  中文/英文共用同一套带占位符的文案模板（`TEXTS` 字典）；
- 上传的 CSV 自动尝试 UTF-8、GBK 两种编码，导出文件使用 `utf-8-sig` 保证 Excel 打开不乱码。
